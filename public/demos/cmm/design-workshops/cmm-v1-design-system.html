07 — Anti-Preferences

Hard No Wall

If it smells like any of these, kill it. Run this check before shipping anything.

Color
Purple-to-orange gradients. Pastels. Neon. Corporate blue #0066FF.
Typography
Serif fonts. Handwriting. Text shadows. Outlined/stroke text.
Layout
Hero sliders. Masonry grids. Horizontal scroll. Desktop hamburger.
Animation
Bouncing elements. Confetti. Anything >600ms. Slide-from-left spam.
Imagery
Stock handshakes. Corporate illustrations. AI art. Emoji as icons.
Components
Glassmorphism. Pill buttons. Modal on page load. Cookie walls.
Content
"Leverage", "synergy", "delve". "Submit" buttons. "Click here".
Vibe
Floating mockups. Gradient mesh heroes. "AI-powered" badges. Template flow.
"Smells Like" Test — run before shipping
